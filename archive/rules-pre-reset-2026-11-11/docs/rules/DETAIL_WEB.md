# Web 实施细则

本文件补充 WEB，只保留当前 Web 移动端、自动化和部署验收要求。

## 1. 移动端页面

### 1.1

使用真实 Android Chrome 或指定移动浏览器观察页面；桌面窗口、Headless 和静态 DOM 不能替代真实屏幕证据。

### 1.2

关键操作保留前后截图，检查页面、按钮、页签、资源和弹窗是否与真实游戏状态一致；节点存在不等于屏幕可见或可点击。

## 2. 自动化与存档

### 2.1

全局行动调度器、智能自动购买器和 UI 渲染相互独立。玩家手动操作立即生效，策略恢复只在下一次策略 tick 进行。

### 2.2

本地测试隔离浏览器 profile 和真实存档，保护用户存档目录；计时、倍率和阶段门控至少覆盖默认值与边界值。

## 3. 部署验收

### 3.1

源码仓库是唯一功能修改入口；部署副本只由同步流程更新，不直接手工拼接功能文件。

### 3.2

部署后检查线上页面、关键功能、资源加载和版本输入。线上不可访问、功能失败或验证未执行时分别报告，不把本地服务器结果写成线上 PASS。

## 4. 结果记录

### 4.1

记录浏览器、设备、存档、提交身份、操作步骤、截图和结果；结果只使用 PASS、FAIL、BLOCKED 和 NOT RUN。
