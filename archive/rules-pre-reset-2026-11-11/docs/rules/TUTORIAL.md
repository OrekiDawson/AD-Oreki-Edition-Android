# 教程、界面与文档

本文件只保留当前教程、界面语言和玩家文档规则；详细事实与测试结果放入 FACTS 或验证记录。

## 1. 教程内容

### 1.1

原版教程正文与 MOD 附录分开维护。MOD 功能变化同步 Android/Web；不得把 MOD 功能冒充原版内容，也不得删除仍在使用的原版正文。

### 1.2

教程解释机制、条件、操作、收益和风险，必须达到新手可执行的详细程度。玩家可见内容、游戏术语、代码注释和普通文档使用简体中文；代码符号、命令和协议名称保留原文。

### 1.3

教程内容使用 `web/AD-Oreki-Edition/src/core/oreki-tutorial-data.json` 作为唯一正文源；生成文件由脚本产生，不直接手改生成物。

## 2. 双端渲染

### 2.1

Web 渲染器和 Android 生成器必须保留教程标题、表格、列表、粗体、代码和转义内容的语义；不支持的语法必须显式转换或由校验器报错。

### 2.2

玩家不得看到原始 Markdown 标记、残缺表格、反引号、制表符或未转换的标题。Android 生成结果必须保留表头、行列关系、数值、条件和说明。

### 2.3

修改教程正文、生成器或渲染器后运行 Web 与 Android 定向渲染测试，并用真实 Web/Android GUI 核对关键页面。

## 3. 界面与术语

### 3.1

官方导航结构、页面顺序、Current Tab、深色模式和移动端触控尺寸按对应平台规则执行；Android/Web 可以采用不同布局，但核心机制和阶段条件必须一致。

### 3.2

统一使用官方简体中文术语：“无限”“永恒次数”“永恒点数”“现实”“天神”“自动购买器”“大坍缩”等，不混用英文或自造译名。

### 3.3

无限阶段隐藏全部永恒层内容；永恒阶段必须显示永恒次数和永恒点数；现实内容只能在真实现实结算后显示。

## 4. README 与文档

### 4.1

README 只承担当前项目说明、快速开始、用法和入口，不写开发流水账、R 编号、任务交接或一次性验收记录。详细规则、教程数据、事实和测试证据使用专门文档。

### 4.2

教程、README、代码注释和界面文案变更后检查中文术语、链接、命令、生成结果和实际运行状态；未验证内容不得写成完成。

## 5. 验收

### 5.1

教程修改至少检查新手流程、阶段门控、移动端布局、弹窗、长文本、表格、特殊符号和生成结果。

### 5.2

测试结果区分 `PASS`、`FAIL`、`BLOCKED` 和 `NOT RUN`；静态文件检查不能替代真实 GUI 显示验证。
