# Android 任务索引

本目录记录 **Android 端各轮任务**的生命周期与结论。任务编号格式 `R<轮次>`，如 `R82`。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 进行中 | 本轮正在执行 |
| 已完成 | 已交付并通过验收（或已如实标注未覆盖项） |
| 已作废 | 前提被推翻或结论错误，不得再引用 |

单 Agent 模式下不再有「领取 / 分派 / 队列」概念，任务由当前会话直接执行。

## 历史任务（R50 及以前）

R50 及更早的任务单仍在 `tasks/` 下按原文件名保留，**作为历史记录**，不再维护状态。
其中包含已废止的多 Agent 角色（`android-agent` / `web-agent` / `rea-agent` 等），
这些角色在当前单 Agent 模式下不存在，任务单里的「负责」字段只表示当时的执行者。

`R50-*.md` 中出现的「进行中 / 待领取」是当时的快照，**不代表当前状态**。
需要判断某个功能是否已实现，以当前代码与 `docs/FACTS.md` 为准。

## 维护约定

1. 每轮任务开单时在「当前与近期任务」加一行，完成后更新状态。
2. 状态必须与实际提交和验收证据一致，不得虚报。
3. 未覆盖的验收项在任务单里明确写「未验证」，不得写成已完成。
4. 历史任务单不追改；结论被推翻时在「已作废」登记原因。
5. `reports/` 存放实测证据，`docs/` 存放长期规则与事实，三者不互相复制。
