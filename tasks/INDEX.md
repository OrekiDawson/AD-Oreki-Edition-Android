## 维护约定

- 主 Agent 建单、分派、验收；子 Agent 只回写自己那一份。
- **同一文件同一时间只允许一个 Agent 修改**，冲突写进任务单的「禁止修改」栏。
- 任务单写入不代表完成，以代码 + 实测证据为准。

## 任务单模板（AGENTS §55 / §56 要求，2026-11-01 起强制）

新建任务单必须含下列字段，缺项即不合格。

### 元信息（十一项）

| 项 | 说明 |
| --- | --- |
| 任务编号 | `R50-XXX-NN` |
| 创建时间 | 真实系统时钟，格式 `2026年11月1日 15:11`，不得推测 |
| 创建者 Agent ID | 建单者 |
| 负责 Agent ID | 最终负责者 |
| 实际执行者 Agent ID | 真正动手的人；与负责者可不同 |
| 更新者 Agent ID | 最近一次写入者，每次更新必改 |
| 贡献者 | 列出所有实际贡献的 Agent；主 Agent 汇总时不得吞并他人贡献 |
| 优先级 | P0~P6，见 `RULES_INDEX.md §2` |
| 状态 | 见下方生命周期 |
| 来源 | 用户执行令原文或上游任务号 |
| 禁止修改 | 同一文件同一时间只许一个 Agent 改，冲突写这里 |

### 生命周期（五阶段，不得混淆）

| 阶段 | 含义 | 对应索引状态 |
| --- | --- | --- |
| 已创建 | 任务单写入文件并提交 | 待领取 |
| 已发送 | 已投递给执行者 | 待领取 |
| 已接收 | 执行者确认收到 | 待领取 |
| 已开始 | 执行者有实际动作 | 进行中 |
| 已完成 | 有实测证据，经主 Agent 验收 | 已完成 |

**「已发送」不等于「已接收」**：消息在发送方回合结束时才刷出（R50-SCHED-01 实验 A 实测 292 秒），未确认收到前不得假定对方已知情。

### 后台构建汇报八项（AGENTS §55.4）

负责 Agent ID / 构建目标与任务编号 / 构建命令 / 进程 PID 或任务标识 / 日志文件路径 / 启动时间 / 当前状态（未完成一律「构建中」）/ 后续验证步骤。

**只提交启动命令不算已启动**；**APK 文件存在不等于构建成功**（须走 §55.6 七步）。

### 文体（AGENTS §51）

禁第一人称：不得出现「我 / 我们 / 我认为 / I / We / My / Our」。

> 注意：任务单内若写了第一人称扫描命令，命令本身会被扫中，属假阳性，按行号人工剔除。
