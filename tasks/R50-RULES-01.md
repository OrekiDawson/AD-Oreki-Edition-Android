## 三、P0~P6 优先级定义

| 级别 | 名称 | 内容 | 约束力 |
| --- | --- | --- | --- |
| P0 | 安全、权限与用户授权 | 用户授权边界；禁止未授权部署/发布/不可逆操作；Git 数据保护与危险操作禁令；文件、密钥、账号与敏感数据保护；杀毒软件与系统安全；设备、AVD 与真机操作限制；保护其他 Agent 未提交工作 | 任何效率优化不得突破 |
| P1 | 真实性、证据与时间 | 禁止编造执行结果/测试结果/完成状态；严格区分【实测】【读码】【推断】【未知】；时间来自真实系统时钟；中国大陆默认北京时间；Agent 间机器时间用 ISO 8601；文件与用户可见输出用自然时间；禁止推测补造时间；重要结论保留可追溯证据 | 任何结论不得绕过 |
| P2 | 任务责任与可追溯 | 正式任务须有独立任务单；须写创建者/负责/实际执行者 Agent ID；禁第一人称；状态、交付物、验收结果明确；建单后先提交、Push、核验远端再分派；不得覆盖在途任务与未提交修改；创建/接收/开始/完成/验收须区分 | 流程强制 |
| P3 | 多 Agent 协作效率 | 控制单回合时长；长命令/构建/批量操作拆分；按 busy/queueBusy 动态派发；避免向忙态 Agent 堆任务；降低重复上报；记录消息发送/入队/接收/确认/执行/完成时间；避免争抢同一资源；只优化有证据的瓶颈，不擅自重构平台底层通信 | 有证据才可优化 |
| P4 | 开发执行与资源管理 | 快速迭代；优先最小有效改动与真实测试；合理使用专项 Agent；控制并行、内存、构建与模拟器资源；避免重复构建；先查工作区与在途任务；保护硬链接；可靠构建/签名/测试流程 | 执行层 |
| P5 | 项目功能与业务要求 | AD 专属：双端等价、默认 10000 倍速、180 分钟内真实终局、智能自动购买器统一调度、间隔不得绕过、教程唯一正文源、教程全中文化、原版导航结构、真实新档端到端测试不得伪造 | 仅限本项目 |
| P6 | 文档、报告与交付 | 四仓库 README 维护；README 与代码一致；Linux/macOS 说明；中文 Git 提交信息；任务单/报告/交付文档格式；APK 与构建产物交付；文件命名与目录规范 | 交付层 |
