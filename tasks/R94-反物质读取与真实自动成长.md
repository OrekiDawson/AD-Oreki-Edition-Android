## 一、P0 根因：绑定表把「字段描述符」当成了「二进制类名」

### 1.1 静态证据链（不猜混淆名）

| 事实 | 证据 |
|---|---|
| `iq0.d` 是反物质货币容器 | `work/base_decoded_321/smali_classes2/iq0.smali:.field public static final d:Lop0;` |
| `op0` 是反物质货币实现 | `op0.smali`：`.super Ldw;`（= `iq0` 子类），`public final K()LBigDouble;` 取当前值、`public final C(BigDouble)Liq0;` 加值 |
| `iq0.w` 是无限点数货币 | `iq0.smali:.field public static final w:Lyp0;`，`yp0` 同样 `.super Ldw;` |
| 绑定表登记形式 | `build/kt/generated/OrekiBaselineBindings.kt` 旧内容：`put("bq0", "Liq0")`、`put("rp0", "Lyp0")` |
| 生成器缺陷 | `scripts/build_kotlin.py`：`mapping[old] = entry["to"].split(".")[-1].rstrip(";")` —— 对无包名的 `Liq0;` 会留下前缀 `L` |
| 运行期后果 | `OREKI_API_MISS: missing class bq0` / `missing class rp0`（R93 日志实测）⇒ `currencyHolderCls()`、`currencyImplCls()` 均为 null ⇒ `antimatterCurrency()` null ⇒ `antimatterValue()` 两条路径都 null ⇒ `prestigeBatch` 恒 noop |

### 1.2 修复（Kotlin 生产路径 + 生成器）

1. `scripts/build_kotlin.py` 新增 `_descriptor_to_binary_name()`：去尾部 `;`、去前缀 `L`、`/`→`.`；生成结果变为 `put("bq0", "iq0")`、`put("rp0", "yp0")`。
2. 生成的 `OrekiBaselineBindings.className()` 增加运行时 `normalize()` 兜底（旧生成文件也能自愈）。
3. 这同时修正**所有**短名重映射绑定（不止反物质），属于系统性 ABI 修复，符合 RG02-02「完整描述符、禁止短名猜测」。
