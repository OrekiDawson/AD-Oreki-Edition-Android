## 四、术语规则

1. 以 **Android 官方简体中文游戏界面**为术语基准
2. EC / ID / IC / IM / RM / TD / DT / TP / IU / DM / DE / DU 等缩写，面向玩家的可见文字**必须给中文名**
3. **V、X 等单字母**必须结合上下文判断实际含义，不得简单保留
4. 薇相关的机制、解锁条件、挑战、升级、玩法说明必须完整翻译
5. 内部代码键、存档键、节点 ID 可保留原值，但**不得泄漏到教程界面**
6. 翻译必须准确保留原意、数值、条件、操作顺序、机制关系

## 五、禁止

- 只翻译章节标题、正文留英文
- 隐藏英文、删段落、替换成空白来制造"通过"假象
- 遗漏原有知识点
- Web / Android 各维护一份不同文本
- 用英文扫描通过代替人工上下文检查
