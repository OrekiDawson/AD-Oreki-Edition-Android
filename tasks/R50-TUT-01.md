## 四、术语规则

1. 以 **Android 官方简体中文游戏界面**为术语基准
2. EC / ID / IC / IM / RM / TD / DT / TP / IU / DM / DE / DU 等缩写，面向玩家的可见文字**必须给中文名**
3. **V、X 等单字母**必须结合上下文判断实际含义，不得简单保留
4. 薇相关的机制、解锁条件、挑战、升级、玩法说明必须完整翻译
5. 内部代码键、存档键、节点 ID 可保留原值，但**不得泄漏到教程界面**
6. 翻译必须准确保留原意、数值、条件、操作顺序、机制关系

## 五、禁止

- 只翻译章节标题、正文留英文
- 隐藏英文、删段落、替换成空白来制造"通过"假象
- 遗漏原有知识点
- Web / Android 各维护一份不同文本
- 用英文扫描通过代替人工上下文检查

### 12.2 判定与取舍（逐条理由）

| 原文写法 | 处理 | 理由 |
| --- | --- | --- |
| `START / SAM / SIP1 / SEP1 / STP / TTF / ACH1~ACHNR` | 正文改中文名，标识只在附录 A 对照表出现 | 这些是复兴树节点按钮上的英文字母缩写，翻掉会找不到节点，所以「正文中文 + 附录可查 + 步骤里加一句悬停看中文说明」三者一起给 |
| `EC / ID / IC / IM / RM / RU / TD / DT / TP / IU / DM / DE / DU / UI / MOD` | 正文删缩写，只留中文名 | 中文名在游戏界面上真实存在，缩写对玩家没有信息增量 |
| `log10 / log2 / min / max / floor` | 改写为「以 10 为底取对数」「取较大值」「向下取整」 | 玩家要按公式核对数值，中文写法同样能算，且不再出现英文字母 |
| `10^n / 2^已购买次数` | 改写为「10 的「已买次数」次方」 | 同上；示例值（第 1 次 10、第 2 次 100）补在前面，读者不必自己代入 |
| `V` | 还原为「薇」 | 上下文指天神薇，不是变量 |
| `N`（「价格：N 无限点数」「至多 N 个符文」） | 改为「另有一行价格」「符文枚数不超过上限」 | 原文这里只是占位符，界面显示的是具体数字 |
| `X/12900` | 改为「已凑到的数量 / 12900」 | 同上 |
| `R37-A`（版本轮次） | 删除 | 内部版本号，玩家不需要 |
| `autoEC` | 删除（正文只说「自动启动永恒挑战」开关） | 配置键不得泄漏到教程界面；界面上这个开关就是中文名 |
| `wiki / break / run` | 「维基」「打破无限」「这一轮现实」 | 普通英文词，直接翻 |
| `Web / Android` | 「网页版」「安卓版」 | 普通名词有对应中文，比平台名更好懂 |
| `Oreki` | 保留 | 作者名，且常驻按钮标题「打开 Oreki 中文教程」里就有 |
| `DLC`（成就 41「无需 DLC」） | 保留 | 成就原名，改了与成就列表对不上 |
| `Emoji / Blobs` | 保留 | 记数法下拉框里的字面值，改了选不到 |
| `F 键 / 按 A / ALT+ / 上上下下左右左右 B A` | 保留 | 键盘按键字面值，翻成中文就按不出来 |
