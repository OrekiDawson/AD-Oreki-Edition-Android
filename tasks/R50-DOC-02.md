## 三、需要先修的高危代码问题

### 3.1 Android `installOrekiTest` 设备安全【已完成，commit `eff53b1`】

**原缺陷**：只判断 `adb devices` 里存在任意 `device`，`adb install` 无 `-s`。
**后果**：用户真机是唯一在线设备时会直接装到真机。

**修复**：
1. 只解析 `emulator-<数字>` 形式的 serial（真机 serial 形式不同，天然排除）
2. 逐个用 `ro.boot.qemu.avd_name`（回退 `ro.kernel.qemu.avd_name`）确认 AVD 名为 `oreki_test`
3. 命中 0 个或多个一律抛异常拒绝；镜像无 AVD 名属性时，仅在「确认 qemu 且只有一台模拟器」才接受并显式告知
4. 安装用 `adb -s <serial> install -r`，即使中途插入别的设备也不会误装

**已验证**：`./gradlew tasks --offline`（JDK17）语法通过，任务正常注册。
**未验证**：运行时拒绝行为（无设备 / 名不匹配 / 多台歧义）需 AVD 空闲后实测三种情形。
