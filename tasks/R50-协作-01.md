## 1. 调整目标

当前仅剩一个 Android 专项 Agent。为减少多 Agent 通信开销、忙态排队与调度成本：

- 主 Agent 成为**唯一任务调度者与项目总负责人**，并直接承担日常开发
- Android-Agent 从常驻执行模式改为**按需调用的专项 Agent**
- **不删除** Android-Agent，不破坏其配置、历史记录、工作目录与专项能力

本调整为协作模式优化，**不是永久放弃多 Agent 能力**。

## 4. 主 Agent 即时生效的行为变更

1. 不再为「形式上的分工」把普通任务派给 Android-Agent
2. 日常开发、代码修改、测试协调、问题分析、验收与交付由主 Agent 自己做
3. 仅 Smali 分析/修改、Android 专属定位、Gradle 构建问题、签名与安装验证、模拟器专项测试、需独立视角时才调用 Android-Agent
4. 调用前检查 busy / queueBusy / 当前阶段 / 未完成任务 / 未消费消息
5. 主 Agent 自己也要遵守 §55：耗时操作后台化，不把回合浪费在等待上
