## 9. Web 移动端适配：以定向 UI 验证为验收标准（2026-10-29 用户确立，长期有效）

移动端适配**以界面实际表现为验收依据，不要求全量测试套件**：

- 只查本轮改动涉及的界面：多宽度布局/横向溢出/截断、侧栏与按钮触控目标、
  滚动/弹窗/输入框与软键盘布局、常驻中文教程入口显示。
- 纯 CSS / 布局 / 触控 / 响应式改动：**不跑**全仓库回归、不跑全机制测试、不跑全浏览器矩阵。
- 同轮若也改了玩法、存档、计时、速度倍率或自动化，才对那些逻辑各自做定向验证。
- 仍必须在 **Android 模拟器 Chrome** 里打开真实页面（不能用桌面缩放代替）；
  验已部署版本就开真实 Pages，只改本地代码先验本地页面、不为纯 UI 重复部署。
- 报告只写：改了什么、实际查了哪些界面、结果、未覆盖项；
  **不得把定向 UI 测试说成全量回归通过**。
