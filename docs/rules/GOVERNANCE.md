# 规则制定与维护
权威：本文件；范围：规则系统维护；来源：§78；状态：生效。

新增前查重与查冲突；相同要求修订原位置，不能继续追加平行正文。明确范围、触发、动作、成功判定、必要例外和失败处理；登记编号、名称、优先级、来源、状态、权威位置及替代关系。
用户明确授权优先；同级遵循更新且明确的用户要求，不能用普通规则绕过安全。不能确定的冲突仅暂停受影响部分，保留原文并报告。
历史编号、锚点与来源不重排、不复用。归档只保留证据，不能再作为同时生效的第二正文。临时任务角色/日期/哈希/PID 只放任务上下文。
常驻入口稳定、短且不含动态环境。专项按职责加载，任务级按需读取；禁止每个子 Agent 通读历史归档。
独立仓库的同版规则镜像具有同一权威，不是两份独立标准。跨仓更新核对内容哈希；隔离分支合并前由实际维护者确认共享 inode、在途变更与镜像版本。
规则维护不得停止其他已授权开发，不修改其他任务的计时与工作区；记录迁移对照、只提交规则文件。
