# 教程与文档实施细则

本文件补充 TUTORIAL，只保留当前教程、界面、术语和 README 验收要求。

## 1. 教程修改

### 1.1

原版教程正文与 MOD 附录分开维护；教程内容使用 Web 的唯一正文源，Android 生成文件由脚本产生，不直接手改。

### 1.2

教程必须说明机制、条件、操作、收益和风险，达到新手可执行的详细程度。玩家可见内容和游戏术语使用简体中文官方译名。

## 2. 双端渲染

### 2.1

Web 与 Android 必须保留标题、表格、列表、粗体、代码和转义内容的语义；不支持的语法必须转换或由校验器报错。

### 2.2

玩家不得看到原始 Markdown、残缺表格、反引号、制表符或未转换标题。教程修改后运行两端定向渲染测试，并核对真实 GUI。

## 3. 导航与阶段

### 3.1

保持原版导航、Current Tab、深色模式、移动端触控尺寸和可读性；两端布局可以不同，但核心功能和阶段条件必须一致。

### 3.2

无限阶段隐藏全部永恒层内容；永恒阶段显示永恒次数和永恒点数；现实内容只能在真实现实结算后显示。

## 4. README 验收

### 4.1

README 只写当前项目说明、快速开始、用法、目录和入口，不写流水账、任务交接、轮次编号或一次性验收记录。

### 4.2

每次 README 或相关功能变化后检查中文术语、链接、命令、路径、生成结果和实际运行状态；没有事实依据的内容删除，不猜测补齐。

## 5. 结果分级

### 5.1

教程和 GUI 验收结果只使用 PASS、FAIL、BLOCKED 和 NOT RUN；静态文件检查不能替代真实显示验证。
