# Web 开发与轻量验收
权威：本文件；范围：Web；来源：原 Web 平台条款、§9、§72、§75；状态：生效。

- 使用真实独立上游 commit 与当前源码，不追随 Android 版本号。Web 原生技术保持现有架构，双端行为等价不要求移植 Kotlin 技术细节。
- 只验证本轮修改与实际受影响依赖，优先已有定向测试；代码/依赖未变时复用证据。核心机制、存档、底层循环、响应式、版本迁移或真实回归风险才扩大范围。
- 需要 Android Chrome 行为验收时必须使用真实 Android Chrome 默认视口；桌面 Headless 不能冒充。无需每轮完整页面复查。记录环境、浏览器版本与实际结果。
- 本地测试隔离用户浏览器 profile 与真实存档，保护 _saves/；计时修改日常覆盖 F=1 与中间倍率，必要发布/里程碑补 F=10000，未覆盖如实报告。
- 默认只用现有依赖离线构建；确缺必要包才补齐，不顺手 npm update/audit fix。
- 导航沿用原版；保持移动端触控与可读性。MOD 自动购买默认 10000 ms，合法范围 1000–60000 ms，保留已有合法值；改间隔立即生效，关闭立即停止排队接管，不影响手动操作。
- Pages 仅在授权且必要验收通过后部署，核实部署任务与实际发布结果。Android 阻塞不自动阻止独立 Web 交付。
- 其余平台专属流程见 DETAIL_WEB.md；重复条文只作来源，不再次立规。
- **RG02-06 模块语法与构建证据**：仓库声明 CommonJS 而生产文件由项目构建器按 ES Module 加载时，裸 `node --check` 的模块解析错误不能直接视为源码语法缺陷；优先使用实际 bundler/项目校验链和定向测试。单独测试通过不等于整体构建或线上部署已通过；不能为绕过检查擅改仓库整体 `package.json` 模块类型，最终结果分别记录。
