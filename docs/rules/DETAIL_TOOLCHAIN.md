# 工具链实施细则

本文件补充 TOOLCHAIN，只保留当前工具、网络、浏览器、模拟器和资源管理要求。

## 1. 工具与环境

### 1.1

优先复用当前正式稳定工具和项目 Wrapper；先查路径、版本、架构和依赖，不重复安装或擅自升级。

### 1.2

Linux 优先，Windows 保持兼容。脚本必须明确路径、权限、换行、大小写和工具行为差异，不写死个人路径。

## 2. 搜索与分析

### 2.1

文本和文件搜索优先使用 rg；APK、DEX、ABI 和基线分析优先复用 REA、JADX、apktool、Rust 和 Android SDK，不重复无关全量分析。

### 2.2

外部资料和工具能力以当前实际检查为准；凭据只存用户环境或 keyring，不进入 Git、日志、README 或报告。

## 3. 浏览器与模拟器

### 3.1

共享浏览器实例、标签页、AVD、ADB 输入、截图、UI dump、logcat 和投影资源必须串行；先核对归属，不重复启动或误关有效任务。

### 3.2

真实 GUI 测试切换用途前停止前一个目标包；长跑期间不得 force-stop 目标包或清除其数据。设备和服务器参数以当前环境为准。

## 4. 进程与资源

### 4.1

同时检查内存、CPU、IO 和进程归属，保护用户进程、Harness 和其他 Agent。只停止自己拥有的进程。

### 4.2

同一构建树、DEX 注入目录、签名密钥、APK 输出目录和基线临时目录不得并发使用；候选构建使用唯一暂存目录和产物身份。

## 5. 故障处理

### 5.1

记录实际命令、时间、日志、退出结果和释放条件；一次修复尝试仍失败时停止重复操作，保留现场并推进不依赖该环境的工作。

### 5.2

缓存命中、静态分析和独立 DEX 只能作为局部证据，不能冒充完整 APK 构建或真实运行验收。
