# 仓库目录与中文命名约定

本文件说明 Android 仓库各目录的职责，避免任务、构建日志和历史材料再次散落到根目录。**中文化以玩家、开发者实际阅读体验为目标，不牺牲构建、GitHub Actions、ABI、存档和历史证据的兼容性。**

## 根目录保留什么

根目录仅保留以下性质的入口：

- **工程与自动化约定文件**：`README.md`、`AGENTS.md`、`CLAUDE.md`、`.github/`、`.gitignore`、`.gitattributes`、`.editorconfig`、Gradle Wrapper 与 Gradle 配置、签名配置示例等。此类文件名不可随意中文重命名。
- **正在使用或可能被构建脚本调用的源码和工具目录**：`app/`、`agp/`、`gradle/`、`baseline/`、`scripts/`、`tools/`、`ops/`、`skills/`。未经引用审计不移动目录，也不“整理”运行中的工作树。
- **有明确用途的数据目录**：`docs/`（规则与技术说明）、`tasks/`（有效任务）、`reports/`（运行与验收证据）、`savestates/`（脱敏测试存档）、`analysis/`（分析中间结果）、`reconstructed/`（复原与验证代码）、`archive/`（历史归档）。

`WEB_ANDROID_DIFFERENCES.md` 保留原路径，指向 Workspace 的唯一双端差异台账。

## 资料去向

| 资料性质 | 唯一推荐位置 |
| --- | --- |
| 当前开发任务与验收检查点 | `tasks/` |
| 用户可读说明、长期规则与技术指南 | `docs/`，标题与正文用简体中文 |
| 分轮次测试结果、APK/设备运行证据 | `reports/` |
| 历史构建日志 | `reports/历史构建日志/`，旧 `build_logs/` 不再作为归档入口 |
| 已停用任务、旧规则、历史暂停事件 | `archive/`（历史暂停记录：`archive/项目暂停记录.md`） |
| 原版输入与可复核分析材料 | 当前 `baseline/`、`analysis/`、`reconstructed/` 保持原路径；旧 3.19 输入记录已归档为 `archive/原版3.19输入文件记录.txt`，不得擅删或改写 |

## 中文化规则

1. 面向人的说明、PR 标题、Issue、发布说明、测试总结与主要注释优先使用**简体中文**，保留代码/API/专业术语的准确原文。
2. 新增独立文档可以使用中文文件名，但不得改变已公开的 URL、GitHub 标准文件名或被脚本引用的路径。旧报告名称保持原样，避免历史引用断裂。
3. `README.md` 是唯一根目录入门说明；新增专题不要在根目录另起 `STATUS*.md`、`HANDOFF*.md`、`REPORT*.md`，应分别归入 `tasks/`、`docs/`、`reports/`。
4. 构建生成物应位于被忽略的构建输出目录；必要的公开日志在 `reports/` 留证，敏感信息、私人存档、令牌和签名密钥不得提交。
5. 文件整理不等于证据清除。迁移历史材料要保留原文和 Git 追溯，并只修复必要的**仍在使用**的路径引用；不得趁整理修改游戏逻辑、任务编号或验收结论。
6. Android 业务仍坚持 Kotlin-only，整理不得改动游戏 DEX/Smali 业务或当前正在验收的候选 APK。

任何大规模技术目录中文改名，都须首先证明脚本、CI、IDE 和 Android 构建路径全部兼容；否则**保留约定英文路径、提供中文索引**。
