## 3. R103-01 阶段门禁（P0，已修复）

真实 AVD（API 37，zh-CN）+ 官方 3.21 同档对照，证据在 `docs/avd-acceptance/2026-11-12-R103/`
与 `2026-11-12-3d924271/`。

- 新档：无无限/永恒/现实入口与沙漏；首次真实大坍缩进入无限阶段；此时无永恒入口、未自动 Break Infinity。
- 非法恢复：`currentSubTab=timeStudies` 启动后被原版 sanitize 回合法页（截图 07/16）。
- canEternity 边界：紫色永恒按钮只在真实阈值出现；手动永恒真实结算（`OREKI_ET: settled ep=0->9.23e14 bigE=0->1`）。
- **修复的 P0**：合法永恒存档（et=1 与 et=25 两份真实档）冷启动后，侧栏/底栏没有「永恒」入口，时间研究不可达。
  根因：`OrekiStageAuto.stageEternityReachedDirectRead()` 的 8ms 缓存用 `Long.MIN_VALUE` 当哨兵却直接做
  `now - cachedAt`，long 溢出使差值恒 <8ms，永不重算、永远 false；该值经 `f82.j()` trampoline 影响原版 12 个
  调用点。另有启动时序问题：原版导航可见性只算一次且早于存档加载，无重算入口。
  修复：缓存哨兵显式判断；`OrekiNavRefresh` 在阶段确定后于 ≤8 次/约 10 秒窗口内重算原版导航可见性；
  删除 R101 的创建期父级分组过滤。修复后侧栏出现「永恒」及 时间研究/永恒升级/里程碑，时间研究页可达
  （截图 23–26、02–04）。
- 未修改任何存档字段、未伪造解锁；只读阶段判定 + 原版 UI 可见性重算。
