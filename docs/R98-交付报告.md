## 3. 根因分组

- **A 组｜原版每帧重设可见性**：`MainActivity.smali:34923` 每帧 `q51.E(t2, f82.j())`；
  只写一次 `GONE` 会被同帧覆盖 → 高度折叠。
- **B 组｜同一 id 多实例**：头部布局被 inflate 多份（`eternityButton` 实测 5 份），
  字段只指向一份 → 按 id 遍历整棵树。
- **C 组｜阶段判据不可靠**：`Player.eternities` 在真实新档被污染为 11（R94 实测），
  不能作唯一依据 → 用 EP / bigEternities / 升级位图 / realities 组合判定。
- **D 组｜玩家配置被策略抢写**：`reconcileManagedAutobuyer` 只有「策略想开 / 实际是关」两维，
  缺少「玩家关的」维度 → 一票否决闩锁。
