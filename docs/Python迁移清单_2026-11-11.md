## P1 分阶段方案（build_mod.py）

`build_mod.py` 是唯一被 Gradle 直接以 `python3` 调用的构建入口，体量 413 KB，包含大量补丁函数。沿用「不得破坏构建链」约束，分阶段迁移：

1. **阶段 1**：把 build.gradle 里对 `python3 scripts/build_mod.py` 的调用改为调用 Kotlin/Rust 实现的编排器；
2. **阶段 2**：按补丁函数逐个迁移到 Kotlin（Gradle 插件）或 Rust（文本/DEX 变换）；
3. **阶段 3**：删除 `build_mod.py`，构建链不再依赖 Python 解释器。

每阶段验收：同一输入 APK → 同一输出 DEX 行为 → `./gradlew installToRelease` 成功 → 产物 SHA-256 记录。
