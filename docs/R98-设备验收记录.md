## FAIL：§7.1 顶部永恒点数未隐藏

截图 `android/reports/R98/06-1inf-gated.png`（1080×2400）实测仍显示：

- 顶部 **「你拥有 0 永恒点数。」** ← 应隐藏
- 底部动作行 **「永恒」** 圆按钮 ← 无限阶段不应出现
- 底部页签 **「时间」** ← 永恒层级页签，不应出现

### 根因（可信推断，有静态依据）

`work/base_decoded_321/smali_classes2/kajfosz/antimatterdimensions/MainActivity.smali:34923`：

```smali
iget-object v2, v0, Lkajfosz/antimatterdimensions/MainActivity;->t2:Landroid/widget/TextView;
invoke-static {}, Lf82;->j()Z
move-result v5
invoke-static {v2, v5}, Lq51;->E(Landroid/view/View;Z)V
```

原版**每帧**用 `f82.j()` 重设 `t2` 可见性。而 `f82.j()` 只读
`Player.eternities > 0 || f82.p()`，该字段在本版本可能被初始化为非零
（R94 实测新档读到 11）。因此：

1. MOD 侧一次性把 `t2` 置 `GONE`（`narrowed=1`）；
2. 同一帧内原版随后按 `j()=true` 把它重新显示；
3. 因为阶段未变化、脏标记已清，MOD 不再重试 → 最终停在"显示"。

即 R98 §1 点名的**「原版缓存/View 更新顺序错误」**：MOD 写入早于原版 UI 通道，
且只在事件时写一次，无法压过原版逐帧重设。

### 修复方向（下一轮）

门控必须在**主线程、原版 UI 通道之后**每帧对账（仅当目标 View 当前可见性错误时写入），
而不是只在阶段变化时写一次。需同时覆盖：

- 顶部永恒点数 `t2` / `0x7f0a05c6`
- 永恒统计块 `i6` / `0x7f0a05c8`
- 现实统计块 `o6` / `0x7f0a0e6a`
- 永恒页签 `jp4.p:Lll2;`
- 「时间」等永恒层级子页签、底部「永恒」动作按钮

`origE=unknown` 还需单独排查：`f82` 反射未解析成功，导致无法比对原版判据，
诊断日志失真（`eternitiesField=0` 也可能是读取失败被误记成 0）。

# 追加记录：R98 第 20–28 轮（顶部永恒点数修复 + 门控目标纠错）

## 1. 顶部永恒点数：FAIL → PASS

**真实根因（已验证事实）**

3.21 原版每帧重设该 View 可见性：

- `work/base_decoded_321/smali_classes2/kajfosz/antimatterdimensions/MainActivity.smali:34923`
  `iget-object v2, ...->t2; invoke-static {}, Lf82;->j()Z; invoke-static {v2, v5}, Lq51;->E(Landroid/view/View;Z)V`
- `work/base_decoded_321/smali/q51.smali:787-815`：`q51.E(View,Z)` 就是
  `true → setVisibility(0)` / `false → setVisibility(8)` 的普通包装。

MOD 原先只在"阶段变化"时置一次 `GONE`，同一帧稍后原版又置回 `VISIBLE`，
所以屏幕上看得到 —— 即 R98 §1 点名的"原版缓存与 View 更新顺序错误"。
同时反证：设备上 `f82.j()` 为真（`Player.eternities` 被污染，与 R94 观测一致）。

**修复（Kotlin，主线程，幂等）**

`GameApi.hideView()` 在置 `GONE` 之外，同时把 `layoutParams.height` 压到 0；
`restoreViewHeight()` 在阶段达成时还原为 `WRAP_CONTENT`。
原版再怎么写 `visibility`，该 View 都占不到高度、不可能显示。
只改可见性与高度，不改文字、不改游戏状态、不写存档。

**设备证据**

- APK `67ad2eb02ca23a230a2a189f3e1d40d13ddc0dc3a5343221b85c2390b4470fb4`
- logcat：`GUI_REFRESH_APPLIED target=stageGate phase=infinity narrowed=3`
- 截图 `android/reports/R98/07-1inf-heightcollapse.png`：
  顶部只剩「你拥有 0 无限点数。」「你拥有 7.12e165 反物质。」，永恒点数行已消失。

| 项 | 结果 |
|---|---|
| §7.1 顶部永恒点数隐藏 | **PASS**（截图 07-1inf-heightcollapse.png） |
