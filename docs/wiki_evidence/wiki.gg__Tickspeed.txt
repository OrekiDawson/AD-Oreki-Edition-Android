Tickspeed increases the speed at which Antimatter Dimensions produce antimatter. It is a crucial mechanic for accelerating progress in the game. Tickspeed is improved by purchasing Tickspeed Upgrades unlocked with the Second Antimatter Dimension, and with various upgrades and Achievement rewards.


== Mechanics ==
Tickspeed simulates reducing the time between antimatter production cycles, effectively multiplying the player's overall production rate.
Each Tickspeed upgrade multiplies production speed of all Antimatter Dimensions by a certain fixed value, which can be most easily increased by getting more Galaxies.


== Tickspeed Boost Formula ==


=== General ===
Tickspeed bonus is kept in game as an "interval" between Antimatter Dimension "ticks". When the game wants to calculate the tickspeed multiplier, a function is called that gets the tickspeed "interval" multiplied by 1,000. Then, since the game only has a length of each tick, the value needs to be inverted to convert it to a "multiplier": 1,000 is divided by this value to get the actual Tickspeed multiplier applied to all Antimatter Dimensions.
Thus, one can derive a formula for the resulting Tickspeed multiplier that looks like this:
1,0001,000*A*TU,
where:

A is value that initially starts at 1 and gets smaller with some achievements:
Achievement 36 multiplies this value by 11.02;
Achievement 45 and 66 both multiply this value by 0.98;
Achievement 83 both multiply this value by 0.95 for each Antimatter Galaxy.
T is the value of the "tick interval" for Antimatter Dimensions. Notice the inversely proportionate nature of the relationship between "interval" and "multiplier" parts — the bonuses actually reduce the denominator, making the Tickspeed multiplier value bigger.
The exact way of calculating this value will be shown further.
U is amount of the Tickspeed upgrades the player has.
For simplicity's sake, the 1,000s will not be written out in all Tickspeed formulas on this page. 1A*TU can be considered a simplified final formula of the Tickspeed multiplier, and 1T can be considered a simplified formula to determine the value of each Tickspeed upgrade.

== Price scaling ==
Every purchase the cost of Tickspeed upgrade will be multiplied by 10.


=== Post-Infinity Scaling ===
After the costs surpasses 1.80e308 (Infinite) antimatter, the scaling coefficient itself starts to increase, multiplying by 10 per upgrade. This number can be reduced by the corresponding Break Infinity upgrade, and later by a certain Eternity Challenge.
